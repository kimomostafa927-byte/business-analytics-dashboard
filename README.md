# INSIGHT – Business Analytics Dashboard

## Project Overview
INSIGHT is a business analytics dashboard designed to visualize sales performance and help users understand key business metrics through interactive charts and tables.

## Features
- Revenue, profit, orders, and customer KPIs.
- Monthly revenue visualization.
- Sales breakdown by product category.
- Recent transactions table.
- Search and filter transactions.
- Products and customers overview.
- Responsive dashboard layout.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js

## Data
This project currently uses sample data generated for demonstration and learning purposes. It is not connected to a live database or backend.

## Purpose
This project was built to practice front-end development, data visualization, and business analytics concepts.

## Future Improvements
- SQL database integration.
- Advanced filtering and sorting.
- Backend development using C#.
- Real-time business data integration.
