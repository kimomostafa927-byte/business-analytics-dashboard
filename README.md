# INSIGHT – Business Analytics Dashboard

## Project Overview
INSIGHT is an interactive business analytics dashboard built to monitor and analyze sales performance through key business metrics, dynamic charts, and data tables.

The project demonstrates how business data can be transformed into clear visual insights to support better understanding of revenue, profit, products, and customer performance.

## Key Features
- **Business KPI Tracking:** Monitor total revenue, total profit, number of orders, and customers.
- **Revenue Analysis:** Visualize monthly revenue trends.
- **Profit Analysis:** Calculate and monitor business profitability.
- **Category Analysis:** Compare revenue across different product categories.
- **Interactive Filtering:** Filter dashboard data by month and product category.
- **Search Functionality:** Search transactions by customer or product.
- **Data Tables:** Explore transactions, products, and customer information.
- **Dynamic Dashboard:** Update KPIs, charts, and tables based on selected filters.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- SQLite
- SQL

## Data & Database
The live dashboard uses sample sales data stored in JavaScript.

A separate SQLite database is included in the repository. It contains sample business tables and analytical SQL queries, including:
- Revenue and profit by product
- Monthly revenue analysis
- Revenue by product category
- Top-selling products
- Customer spending analysis

**Note:** The SQLite database is a separate component and is not currently connected to the live dashboard.
